# Unity 3D Player Controller

A simple first-person controller for Unity 3D projects.

## Features

- WASD or Arrow keys movement
- Mouse look camera control
- Jump with Spacebar
- Sprint with Left Shift
- Smooth movement and camera rotation
- Control for crouching

### Prerequisites

- Unity 2020.3 or higher
- Basic understanding of Unity components

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/unity-3d-controller.git
```
2. Add it to your project.
